# Clasificacion_Genes_Artritis
En el presente se realiza la clasificación de genes obtenidos del ClinVar con el objetivo de ver qué resultados se obtienen al momento de separar las clases de genes con variantes y sin variantes causantes de predisposición a la enfermedad de Artritis, para esto se compararon los modelos de regresión logística, random forest y XGBoosting
